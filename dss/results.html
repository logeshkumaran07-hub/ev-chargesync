How to read this report

Voltage base: the model uses a 0.48 kV line-to-line secondary, or 277.1 V phase-to-neutral. The voltage chart shows all phases for every five-minute interval.

Transformer peak: sums S1, S2, and S3 at each sample. Meter values are reported separately from the OpenDSS energy-meter export.

Snapshot versus daily minimum: the OpenDSS GUI summary shows the currently selected solution point. This report’s voltage range covers the complete daily trace, so its minimum can be lower than the GUI’s final-hour snapshot.

Update after another run: with Python 3.10+ installed, export the named monitors and meter to dss\output, then run py -3 dss\build_results_report.py. The page is self-contained and opens offline.
